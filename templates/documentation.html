REST API Standard

Dokumentasi Integrasi NirvaPay Gateway

NirvaPay REST API memungkinkan aplikasi web, bot Telegram, sistem POS kasir, atau aplikasi toko online Anda untuk membuat tagihan QRIS dinamis berstandar EMVCo secara instan dan menerima konfirmasi pembayaran secara real-time via Webhook.

Production Base URL
https://nirvapay.dasrams.biz.id
Content Format
JSON (application/json)

2. Autentikasi API Key

Setiap panggilan API memerlukan header HTTP Authorization yang berisi Secret Key (sec_live_... atau sec_sand_...) dari dashboard merchant Anda.

Authorization: Bearer sec_live_YOUR_SECRET_KEY Content-Type: application/json
POST /api/v1/invoices

Membuat transaksi pembayaran baru dengan kode QRIS dinamis dan mengembalikan tautan pembayaran.

Request Body (JSON)

Field Tipe Status Keterangan
amount number Wajib Nominal pokok tagihan (Minimal Rp 1.000).
merchant_ref string Opsional ID Pesanan unik dari sistem Anda (Contoh: ORDER-9912).
customer_name string Opsional Nama lengkap pelanggan.
customer_phone string Opsional Nomor WhatsApp pembeli.
callback_url string Opsional URL webhook endpoint di server Anda untuk menerima notifikasi saat lunas.

Contoh Response (200 OK)

{ "success": true, "invoice": { "invoice_id": "INV-20260928-8419", "amount": 25000.0, "unique_code": 143, "total_amount": 25143.0, "qris_payload": "00020101021226610014COM.GO-JEK...", "payment_url": "/pay/INV-20260928-8419", "expired_at": "2026-09-28T01:15:00.000Z" } }
GET /api/v1/invoices/{invoice_id}/status

Mengecek status pembayaran invoice secara langsung (Polling).

{ "invoice_id": "INV-20260928-8419", "status": "PAID", "total_amount": 25143.0, "paid_at": "2026-09-28T01:05:22.000Z" }

5. Webhooks & Payload Verification

Setiap pembayaran yang berhasil lunas akan memicu HTTP POST ke callback_url atau endpoint webhook yang telah Anda daftarkan di dashboard.

{ "event": "payment.paid", "invoice_id": "INV-20260928-8419", "merchant_ref": "ORDER-9912", "total_amount": 25143.0, "status": "PAID", "paid_at": "2026-09-28T01:05:22.000Z" }

6. Contoh Kode Integrasi Multi-Bahasa

1. cURL / Shell
curl -X POST https://nirvapay.dasrams.biz.id/api/v1/invoices \ -H "Authorization: Bearer sec_live_YOUR_SECRET_KEY" \ -H "Content-Type: application/json" \ -d '{ "amount": 50000, "customer_name": "Rama Danadipa", "merchant_ref": "ORDER-5001", "description": "Langganan Layanan VIP", "callback_url": "https://tokoanda.com/webhook/payment" }'
2. Python (httpx / requests)
import httpx import asyncio async def create_invoice(amount: int, order_id: str): url = "https://nirvapay.dasrams.biz.id/api/v1/invoices" headers = { "Authorization": "Bearer sec_live_YOUR_SECRET_KEY", "Content-Type": "application/json" } payload = { "amount": amount, "merchant_ref": order_id, "customer_name": "Budi Santoso", "description": f"Pesanan #{order_id}" } async with httpx.AsyncClient(timeout=10.0) as client: response = await client.post(url, json=payload, headers=headers) data = response.json() print("Payment Link:", data["invoice"]["payment_url"]) return data["invoice"] asyncio.run(create_invoice(50000, "ORDER-5001"))
3. Node.js (JavaScript / TypeScript)
const axios = require('axios'); async function createNirvaPayInvoice(amount, orderId) { try { const response = await axios.post('https://nirvapay.dasrams.biz.id/api/v1/invoices', { amount: amount, merchant_ref: orderId, customer_name: 'Budi Santoso', description: `Pembelian #${orderId}` }, { headers: { 'Authorization': 'Bearer sec_live_YOUR_SECRET_KEY', 'Content-Type': 'application/json' } }); console.log("Invoice Created:", response.data.invoice); return response.data.invoice; } catch (err) { console.error("Error creating invoice:", err.response?.data || err.message); } } createNirvaPayInvoice(50000, "ORDER-5001");
4. PHP (Laravel Http Client)
<?php namespace App\Http\Controllers; use Illuminate\Http\Request; use Illuminate\Support\Facades\Http; class PaymentController extends Controller { public function checkout() { $response = Http::withToken('sec_live_YOUR_SECRET_KEY') ->post('https://nirvapay.dasrams.biz.id/api/v1/invoices', [ 'amount' => 50000, 'merchant_ref' => 'ORDER-5001', 'customer_name' => 'Budi Santoso', 'description' => 'Top Up Saldo Akun' ]); if ($response->successful()) { $invoice = $response->json()['invoice']; return redirect('https://nirvapay.dasrams.biz.id' . $invoice['payment_url']); } return back()->with('error', 'Gagal membuat tagihan pembayaran.'); } }
