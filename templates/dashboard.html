Autentikasi API

Autentikasi dilakukan dengan menyertakan Secret Key (sec_live_...) pada header HTTP permintaan:

Authorization: Bearer sec_live_YOUR_SECRET_KEY
Content-Type: application/json
POST /api/v1/invoices

Membuat Tagihan QRIS Baru

Endpoint ini membuat transaksi baru, mengalokasikan kode unik anti-collision, dan menghasilkan payload QRIS dinamis EMVCo.

Field Tipe Wajib Keterangan
amount number Ya Nominal pembayaran pokok (min Rp 1.000).
merchant_ref string Opsional ID referensi pesanan dari sistem/database Anda.
customer_name string Opsional Nama pelanggan pembeli.
description string Opsional Catatan / detail item pesanan.
callback_url string Opsional URL webhook untuk menerima notifikasi saat lunas.

import httpx
import asyncio

async def create_invoice():
    url = "https://nirvapay.dasrams.biz.id/api/v1/invoices"
    headers = {
        "Authorization": "Bearer sec_live_YOUR_SECRET_KEY",
        "Content-Type": "application/json"
    }
    payload = {
        "amount": 25000,
        "merchant_ref": "ORDER-1024",
        "customer_name": "Budi Santoso",
        "description": "Topup Saldo Akun #1024"
    }
    async with httpx.AsyncClient(timeout=10.0) as client:
        res = await client.post(url, json=payload, headers=headers)
        data = res.json()
        print("Payment URL:", data["invoice"]["payment_url"])
        print("QR Payload:", data["invoice"]["qris_payload"])
        return data["invoice"]

asyncio.run(create_invoice())
const axios = require('axios');

async function createPayment() {
    try {
        const response = await axios.post('https://nirvapay.dasrams.biz.id/api/v1/invoices', {
            amount: 25000,
            merchant_ref: 'ORDER-1024',
            customer_name: 'Budi Santoso',
            description: 'Topup Saldo Akun #1024'
        }, {
            headers: {
                'Authorization': 'Bearer sec_live_YOUR_SECRET_KEY',
                'Content-Type': 'application/json'
            }
        });
        console.log("Invoice ID:", response.data.invoice.invoice_id);
        console.log("Total Bayar:", response.data.invoice.total_amount);
    } catch (err) {
        console.error(err.response ? err.response.data : err.message);
    }
}
